# naruki_visualization
This project was coded using Codex GPT 5.6 Sol.  

A visualization of Naruki's cross ratio moduli space Y of cubic surfaces along with their 27 lines.
Naruki provides an explicit family with four nonzero complex parameters \rho, \lambda, \mu, \nu and shows this family extends to his entire space Y.
The user can vary the four parameters individually and see the corresponding cubic surface with their 27 lines in each four real affine chart x_i = 1 for i = 0,1,2,3.  

As a disclaimer, these surfaces are in CP^3, so this visualization only shows the real cartoon pictures for each cubic surface, thus, one may not see all 27 lines.
